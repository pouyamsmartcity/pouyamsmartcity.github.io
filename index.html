Pouyam Open Source فارسی

Free tools, built in the open.

We build Pouyam, a bilingual Persian and English social world of games, news and creators. Along the way we make tools we needed ourselves, and we give them away: free, open source, no accounts, no tracking.

Turbodrop

Like AirDrop, for every device

Send files, photos and videos between Windows, iPhone, Android, Mac and Linux over your own Wi-Fi. Phones just scan a QR code, no app needed. End-to-end encrypted and resumable.

Website · Download · GitHub

rtlint

Right-to-left and Persian typography linter

Finds and fixes RTL layout bugs and Persian or Arabic typography mistakes in CSS, Tailwind, Bootstrap, React, React Native, Vue, Svelte and HTML. ESLint, Stylelint and Vite plugins, a GitHub Action and an MCP server for AI assistants.

Try it online · npm · GitHub
